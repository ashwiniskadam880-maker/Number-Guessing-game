# Number Guessing Game

## Description

This is a simple Java-based Number Guessing Game. The program generates a random number between 1 and 100, and the user tries to guess it. After each guess, the program provides hints indicating whether the guessed number is too high or too low. The game continues until the correct number is guessed.

## Features

* Random number generation
* User input using Scanner
* Hints for high and low guesses
* Tracks the number of attempts
* Beginner-friendly Java project

## Technologies Used

* Java
* Scanner Class
* Random Class

## How to Run

1. Download or clone the repository.
2. Open the project in any Java IDE (Eclipse, NetBeans, VS Code).
3. Compile and run the `NumberGuessingGame.java` file.
4. Enter your guesses when prompted.
